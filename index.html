Check Tara for Both
💍 For Muhurthams related to Marriage (Vivaham), Starting House Construction (Gruharambham), and Housewarming (Gruha Pravesham), the Tarabalam must be checked for the couple.
🪡 When fixing the Muhurtham for an Upanayanam (Thread Ceremony), this table is useful to check the Tarabalam for both the Vatuvu (the boy undergoing the ceremony) and the Vatuvu's father.
🤝 For those starting a Partnership Business, this table can be used to check the stars for both partners and decide on the appropriate Nakshatras.
ℹ️ Checking Tarabalam for Medium Nakshatras uses the Pariganana method — of the three Janma Taras that would normally be avoided, one is dropped and the Muhurtham is decided using the remaining two. This is called checking Tarabalam through Navaka Bhedam. Shastra recommends this method when one person's Tara suits but the other's doesn't. The exact Taras applicable to both persons are shown in detail here.
📝 How to Use: Select the first person's Nakshatra in the first table. Select the second person's Nakshatra in the second table. The Nakshatras favorable for both will be shown, along with the Tara each corresponds to for both persons.
